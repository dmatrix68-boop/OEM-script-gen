Version 1.1 bringt ein Treiber-Modul, eine Hilfe auf jeder Seite und eine wichtige Korrektur für aktuelle Windows-11-Builds: Ohne `UseConfigurationSet=true` in der Antwortdatei kopiert Windows Setup den `$OEM$`-Ordner dort unter Umständen gar nicht.

## Download

**`OEM-Script-Generator-v1.1.zip`** herunterladen, entpacken, `index.html` im Browser öffnen.

## Neu

- **Treiber-Modul:** Entpackte Treiber (INF) als Pakete mitliefern.
  - Einspielen per `pnputil` in Phase 1 oder Laden durch Windows Setup über `$WinPEDriver$` (NVMe/RAID, Netzwerk).
  - Modellfilter je Paket, damit ein Medium mehrere Gerätemodelle bedient.
  - Leere Pakete für große Treibersammlungen, deren Dateien direkt aufs Medium kopiert werden.
- **Hilfe auf jeder Seite:** Der Knopf „Hilfe“ oder <kbd>F1</kbd> öffnet eine ausführliche Beschreibung aller Optionen, auf Deutsch und Englisch.
- **„Speichern unter“-Dialog** für Projektdatei und ZIP in Chrome und Edge. Der zuletzt gewählte Ordner bleibt gemerkt, auch nach dem Neuladen. Firefox und Safari laden die Datei wie bisher herunter.
- **Spaltensortierung** in der Anwendungsliste. Die Installationsreihenfolge bleibt davon unberührt.
- **Versionsnummer** in der Kopfzeile.

## Korrigiert

- **`$OEM$` wurde nicht kopiert:** Auf Windows 11 (Build 26300) hat Setup `$OEM$` mit einer Antwortdatei ohne `UseConfigurationSet=true` nicht übernommen. Es gab dann keinen Installationsordner und keine Phase 2.
  - Der Generator schreibt den Wert jetzt in die erzeugte und in eine importierte `autounattend.xml` (abschaltbar unter *Einstellungen → Auslöser*).
  - Die Ablage von `$OEM$` steht dabei auf „beide Orte“, weil Setup den Ordner dann im Wurzelverzeichnis des Mediums sucht.
  - Hinweis: Setup kopiert den Ordner der Antwortdatei nach `C:\Windows\ConfigSetRoot`. Auf Multiboot-Sticks wie Ventoy kann das sehr groß werden.
- **Falsches „OK“ in der Zusammenfassung:** Ein gescheitertes Modul, etwa ein nicht installiertes Paket, wurde am Ende trotzdem als OK gemeldet.
- **Fehlende Dateien nach dem Laden einer Projektdatei:** Installer und Treiber stehen nicht in der Projektdatei. Die Platzhalter sind jetzt markiert und lassen sich neu zuordnen, und „ZIP erzeugen“ fragt nach, wenn noch etwas fehlt.
- **Zu große ZIPs:** Über 4 GB oder 65.535 Dateien bricht der Export mit einer Erklärung ab, statt ein defektes Archiv zu schreiben.

*English:* Version 1.1 adds a drivers module (pnputil or `$WinPEDriver$`, with a per-model filter), a help dialog on every page (<kbd>F1</kbd>), a "Save as" dialog that remembers the last folder, and column sorting for the application list. It also writes `UseConfigurationSet=true` into the answer file, because current Windows 11 builds may otherwise not copy `$OEM$` at all, and it fixes a summary that reported OK for a failed module. Download `OEM-Script-Generator-v1.1.zip`, unpack it and open `index.html`.

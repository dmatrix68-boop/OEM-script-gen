Version 2.0 macht aus dem Skript-Generator ein Werkzeug für das ganze Installationsmedium. Der Generator schreibt jetzt die fertige Windows-ISO selbst, erzeugt eine vollständige `autounattend.xml` und übernimmt `.reg`-Dateien. Geprüft wurde das in einer VM mit Windows 11 Pro for Workstations (Build 26340): alle Phasen fehlerfrei, darunter Tweaks, `.reg`-Dateien, Windows-Komponenten, Office, 41 Anwendungen und eigene Installer.

## Download

**`OEM-Script-Generator-v2.0.zip`** herunterladen, entpacken, `index.html` im Browser öffnen.

## Neu

- **ISO erzeugen:** Eine Windows-ISO wählen, der Generator legt die erzeugten Dateien dazu und schreibt eine neue, bootfähige ISO für BIOS und UEFI. Dafür braucht es weder oscdimg noch das ADK oder Adminrechte.
  - Die ISO wird im Browser geschrieben (UDF 1.02 mit ISO-9660-Hülle wie `oscdimg -u2`). Die Quelldateien werden direkt übernommen statt in den Arbeitsspeicher geladen.
  - Build und Editionen des Abbilds werden angezeigt, „Press any key to boot“ lässt sich abschalten, und eine vorhandene `autounattend.xml` kann übernommen werden.
- **Antwortdatei-Designer** (Seite *Antwortdatei*): erzeugt eine vollständige `autounattend.xml`, in die der Generator seine Aufrufe einfügt. Er ist eine Portierung des Generators von Christoph Schneegans ([unattend-generator](https://github.com/cschneegans/unattend-generator), MIT-Lizenz).
  - Sprache und Region, Edition und Produktschlüssel, Hardwareprüfung umgehen, Einrichtung ohne Internet, Computername, lokale Konten mit automatischer Anmeldung, OOBE, Kontosperrung, Kennwortablauf.
  - **pe.cmd:** Ein Skript übernimmt die windowsPE-Phase. Es bestimmt den Zieldatenträger, teilt ihn mit `diskpart` ein (GPT/MBR nach Firmware), spielt das Abbild per `dism` auf und lädt Treiber, auch VirtIO. **Die automatische Partitionierung löscht den Zieldatenträger ohne Rückfrage.**
  - **WLAN:** mit Netzwerkname, Kennwort und Sicherheit (WPA2, WPA3, offen, verborgen) oder als Profil aus `netsh wlan export profile`.
  - **Personalisierung:** Farben, Hintergrundbild, Sperrbildschirm, Sperrtasten, visuelle Effekte, Desktopsymbole und Ordner im Startmenü.
  - **Gasterweiterungen** für VirtualBox, VMware, VirtIO (QEMU/KVM, Proxmox) und Parallels sowie **AppLocker**-Richtlinien.
  - Ein GitHub-Workflow vergleicht den Port bei jedem Push Byte für Byte mit dem C#-Original (86 Fälle) und meldet wöchentlich Änderungen im Original-Repository.
- **Import von `.reg`-Dateien** (REGEDIT4 und 5.00, auch UTF-16). Die Werte laufen im Tweaks-Modul mit, `HKCU` landet im Default-Profil und damit bei allen Benutzern.
- **Import erkennt mehr Dateien:** zusätzlich AppLocker-Richtlinien und WLAN-Profile. Die Import-Seite nennt alle erkannten Dateitypen.
- **Installer-Vorlagen** unter *Eigene Dateien*: Bekannte Setup-Dateien wie Right-Click Tools bekommen Parameter und Phase automatisch. Bei anderen `.exe` erkennt der Generator Inno Setup, NSIS und WiX Burn am Dateianfang. Ein Installer ohne Parameter, der nur kopiert würde, wird in der Tabelle markiert.
- **Tests in GitHub Actions:** PowerShell-Syntax und PSScriptAnalyzer unter Windows PowerShell 5.1 und PowerShell 7, Funktionstests der Registry-Module, ISO-Gegenprobe mit 7-Zip und `udfinfo`.

## Geändert

- **`UseConfigurationSet` folgt dem Zielsystem** (Einstellungen → Auslöser) statt fest auf `true` zu stehen. Bis Windows 11 23H2 kopiert Setup sonst das ganze Medium nach `ConfigSetRoot`. Bei einer Quell-ISO folgt die Auswahl dem Build.
- **Edge-Tweak aufgeteilt:** „Erststart-Assistent ausblenden“ und „Startup-Boost und Hintergrundmodus aus“. Der Startup-Boost ist jetzt eine empfohlene Richtlinie wie bei Schneegans und lässt sich in Edge wieder einschalten. Ältere Projekte bekommen automatisch beide Tweaks.
- **Suchfeld-Tweak** setzt den Wert über ein Einmal-Skript je Benutzer, weil Windows ihn bei der ersten Anmeldung zurücksetzt. Der Tweaks-Zähler zählt `.reg`-Dateien jetzt als je einen Eintrag.

## Korrigiert

- **„PowerShell-Ausführungsrichtlinie auf RemoteSigned fehlgeschlagen: Sicherheitsfehler“:** Die Meldung kam, obwohl der Wert gesetzt war. Der Tweak prüft jetzt das Ergebnis und warnt nur noch bei einem echten Fehlschlag.
- **Suchfeld ausblenden** griff nicht, weil Windows den Wert bei der ersten Anmeldung überschrieb.

*English:* Version 2.0 turns the script generator into a tool for the whole installation medium. It **writes the bootable Windows ISO itself** (BIOS and UEFI, no oscdimg, ADK or admin rights) and adds an **answer file designer** that creates a complete `autounattend.xml`. The designer is a port of Christoph Schneegans' unattend-generator (MIT licence): language, edition, accounts, OOBE, `pe.cmd` partitioning, Wi-Fi, personalization (colors, wallpaper, lock screen), VM guest additions and AppLocker. A GitHub workflow compares it byte for byte with the C# original (86 cases). New are also `.reg` file import, detection of AppLocker policies and Wi-Fi profiles on import, and installer templates and detection (Inno Setup, NSIS, WiX Burn) under *Own files*. Changed: `UseConfigurationSet` follows the target system, the Edge tweak is split in two, and the search box tweak runs once per user. Fixed: a false "security error" for the execution policy tweak. Tested in a VM with Windows 11 Pro for Workstations (build 26340). Download `OEM-Script-Generator-v2.0.zip`, unpack it and open `index.html`.
